# Noble CPA - Deployment Guide

## Quick Start to Live Website (15 minutes)

### Step 1: Sign Up for Vercel (2 minutes)
1. Go to https://vercel.com
2. Click Sign Up
3. Click Continue with GitHub
4. Authorize Vercel to access your GitHub

### Step 2: Deploy Your Website (5 minutes)
1. After signing in, click New Project
2. Look for noble-cpa-website in your repositories
3. Click Import
4. Click Deploy (no configuration needed!)
5. Wait for deployment to complete
6. You'll see a URL like: **noble-cpa-website.vercel.app**

### Step 3: View Your Live Website
- Click the URL to see your website live
- Test it on desktop and mobile
- Try the contact form
- Share the preview link if needed

### Step 4: Connect Your Domain (Optional - 5 minutes)
Once you're happy with the site:
1. In Vercel dashboard, click your project
2. Go to Settings > Domains
3. Enter your domain: noblecpa.ca
4. Vercel will show you DNS records to add
5. Go to your domain provider
6. Add the DNS records Vercel provides
7. Wait 24-48 hours for DNS to propagate
8. Your site will be live at **noblecpa.ca**

## Making Changes

**You:** "I want to change the color to green"
**Me:** Update the code in GitHub
**Vercel:** Automatically rebuilds and deploys
**Result:** Your live website updates instantly!
